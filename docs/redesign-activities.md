# In-class redesign activities

Students learn design by changing charts, not only by watching finished examples. These
activities are ungraded practice. Three equally weighted figure assignments make up 25% of
the course grade. For each, students create an original figure from instructor-supplied data
and a question, submitting only the figure and notes. The 75% final project remains unchanged.
These decisions were confirmed by the instructor on 4 November 2026.

## Classroom routine

Use existing practice time, not an additional lecture segment. **Session 1 uses the final
20 minutes after live coding**; plan 10–15 minutes for the other short redesign activities.

1. Show the audience and question, then run the supplied weak chart.
2. Students diagnose the mismatch before consulting AI: what is hard to see or easy to misread?
3. Individually or in pairs, they change the chart while preserving the specified data and calculation.
4. They explain their choice and reconcile two plotted values with the data.
5. Compare alternatives. The teaching examples illustrate possible choices, not a single answer to memorise.

Start with chart choice rather than decorative ugliness. The supplied code works: the problem
is what it communicates. Do not tell students that a chart type is universally bad.

For today's class, use the Session 1 activity after live coding. Students run the supplied
data preparation and pie-chart cell, then copy and edit the plotting code. Leave the monthly birth

and choose before showing it. Require a title, labelled axes, a brief figure note and checks
against the first and last printed totals. Leave time for a short comparison of answers.
The notebook explicitly separates the later optional practice tasks from these 20 minutes.

## Feedback, not taste

Ask whether the new design answers the question, preserves the calculation, makes comparison
easier, and retains necessary context. Reward a justified alternative. A polished but misleading
chart is not an improvement. Figure notes should identify units, aggregation, missing-value
handling, and source/sample limitations. Distinguish variation from uncertainty.
